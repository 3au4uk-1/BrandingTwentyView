# Канбан производства

**Date:** 2026-09-29  
**Status:** Approved in chat  
**Repo:** BrandingTwentyView

## Problem

Позиция может быть и плёнкой, и производством сразу. Типа «Производство» для этого мало: он один на строку. Отдельного места, куда цех смотрит задачи, нет. Печать и фреза пишут очередь в таблицу. Производству нужна доска в Twenty, которую потом можно дополнить картинками и другими полями. Штатный канбан Twenty это не тянет.

## Goals / non-goals

| In | Out |
|----|-----|
| Модалка на «Реализации», кнопка как у печати и фрезы | Отправка в Google Sheet |
| Флаг «в производство» только вручную | Автофлаг от типа или уточнения позиции |
| Свой канбан «Производство»: три колонки, перенос, раскрытие карточки | Штатный канбан Twenty и отдельный объект задачи |
| Поля на строке позиции | Исполнитель, картинки, файлы |

Исполнитель и картинки намеренно позже. Карточка и экран свои, чтобы их добавить без смены доски.

## Decisions (locked)

| Topic | Choice |
|-------|--------|
| Одна позиция | Одна карточка, пока флаг включён |
| Флаг | Только из модалки. `tip === PROIZVODSTVO` сам его не ставит |
| Снятый флаг | Карточки на доске нет. Дата, время, комментарий и галочки остаются |
| Колонки | «Не взято», «В работе», «Готово» |
| Колонка из галочек | Есть «Готово» → «Готово». Иначе есть «Взято» → «В работе». Иначе «Не взято» |
| Перенос | «Готово» включает обе галочки. «В работе» — только «Взято». «Не взято» снимает обе |
| Закрытая карточка | Название позиции, сделка, дата и время. Пустые дата и время не пишутся |
| Раскрытие | На месте, повторный клик или крестик сворачивает. Поля только для чтения. Правит их модалка, галочки ещё и перенос |
| Порядок в колонке | Дата по возрастанию, затем время `HH:MM`. Время не в этом виде — как без времени. Без времени — после карточек с временем в тот же день. Без даты — внизу. При равенстве — название позиции |
| Отмена сделки | Позиция с флагом всё равно на доске |
| Кнопка | На каждой позиции. Без флага подпись «Производство», без статуса. С флагом: «не взято», «взято» или «Готово» |
| Флаг в таблице | Колонкой на «Реализации» не показываем |

## Architecture

```
Пункт меню «Производство»
  свой экран, три колонки
  читает позиции с флагом и название сделки
  колонку и порядок считает чистая функция
  перенос пишет галочки на позицию
  клик раскрывает комментарий и галочки на месте

«Реализация»
  кнопка «Производство» на каждой позиции
  модалка пишет те же поля, без отправки в таблицу
```

Нового объекта нет. Источник правды — поля строки позиции.

### Поля на `dealLineItem`

Не общие с печатью и фрезой.

| Поле | Тип | Подпись | UUID |
|------|-----|---------|------|
| `vProizvodstvo` | BOOLEAN | В производство | `7fc83b4d-a882-41c5-b7a9-df3b1e87fe4e` |
| `vzatoVRabotuProizvodstva` | BOOLEAN | Производство · Взято | `2dc2890a-853b-4160-b7a5-cc3a0c276a6b` |
| `gotovoProizvodstva` | BOOLEAN | Производство · Готово | `5b0e9ae2-8c49-4cfe-8efe-eb969f48af25` |
| `dataGotovnostiProizvodstva` | DATE | Дата готовности производства | `d90b1112-da27-4511-b1a4-be793b069409` |
| `vremyaGotovnostiProizvodstva` | TEXT | Время готовности производства | `1eba76da-d1f8-4e51-a04e-9c5eb38fe8b1` |
| `kommentariyDlyaProizvodstva` | TEXT | Комментарий для производства | `414d1d12-133e-4f9f-a29f-70f5ed41587f` |

Время — строка `HH:MM`, как у фрезы.

## Modal

Панель как у печати, без кнопки в таблицу и без плёнки. Галочки, дата и время пишутся сразу. Комментарий — когда ушли из поля.

Кнопка подсвечивает статус так же, как печать: спокойная, «взято», «Готово». Без флага статус на кнопку не выносится, даже если старые галочки ещё лежат в полях.

## Board

Колонки слева направо всегда видны, в том числе пустые.

Доска запрашивает позиции с `vProizvodstvo = true` и название связанной сделки. Сделки нет — карточка остаётся, строка сделки пустая. Если курсор Twenty на фильтре не двигается и снова отдаёт ту же страницу, следующий запрос идёт по `id` больше последнего, а повтор той же страницы останавливает листание.

Перенос сразу рисует карточку в новой колонке. Запись не удалась — карточка возвращается, на доске текст ошибки. Перенос внутри той же колонки ничего не пишет.

Не загрузилось — текст ошибки вместо вечной загрузки.

Раскрытая карточка показывает комментарий, обе галочки, дату и время. Менять их на доске нельзя.

## Units

| Unit | Does | Depends on |
|------|------|------------|
| Колонка и порядок | Из флага и галочек делает колонку, из даты и времени — место в колонке | Ничего экранного |
| Доска «Производство» | Рисует три колонки, переносит, раскрывает | Колонка и порядок, поля позиции, название сделки |
| Модалка | Пишет флаг, галочки, дату, время, комментарий. Подпись кнопки | Те же поля |
| Поля | Хранят задачу на строке позиции | — |

## Testing

Колонка и порядок, без экрана:

- нет «Готово» и нет «Взято» → «Не взято»; только «Взято» → «В работе»; «Готово» без «Взято» всё равно «Готово»;
- перенос в «Готово» включает обе галочки, в «В работе» оставляет только «Взято», в «Не взято» снимает обе;
- снятый флаг убирает карточку и не очищает дату, время, комментарий и галочки;
- сортировка: дата, затем время `HH:MM`; иное время как пустое; без времени после времени того же дня; без даты внизу; при равенстве — название позиции;
- подпись кнопки: без флага нет статуса; с флагом «не взято», «взято» или «Готово».

Листание:

- залипший курсор не запрашивается снова;
- следующая страница берётся по id больше последнего.
